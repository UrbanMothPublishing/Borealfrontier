# borealfrontier.com

Static site for Boreal Frontier, hosted on Netlify.

- `index.html` — the whole page (inline CSS, no build step)
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-*.png` — maple leaf icons
- `site.webmanifest` — app/home-screen metadata
- `thanks.html` — shown after the contact form is sent (form handled by Web3Forms, which emails each message)

Netlify settings: no build command, publish directory is the repo root.
